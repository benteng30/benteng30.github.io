# Ben Teng — Portfolio

Personal portfolio site for Ben Teng, Operations & Information Management student at UMass Amherst who builds with data and AI.

Plain HTML and CSS, no build step, hosted on GitHub Pages.

## Files

```
index.html          the whole site (one page with sections)
styles.css          all styling; change --accent to change the color
resume/
  Ben_Teng_Resume.pdf   public resume (no phone number)
```

## Updating

1. Edit `index.html` (search for `[ADD` to find placeholders).
2. Commit and push to `main`. GitHub Pages republishes in about a minute.
